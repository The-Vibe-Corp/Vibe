# Verhaltenskodex

## Unser Anspruch

vibe ist ein offenes Entwicklerwerkzeug. Alle Beiträge, Issues und
Diskussionen sollen respektvoll, sachlich und inklusiv bleiben — unabhängig
von Erfahrung, Herkunft, Sprache oder Meinung.

## Erwartetes Verhalten

- Respektvoller, konstruktiver Umgang in Issues, Pull Requests und Reviews.
- Kritik am Code und an Vorschlägen, nicht an Personen.
- Fundierte Antworten: nachvollziehbare Begründungen, nachprüfbare Ergebnisse.
- Rücksicht auf unterschiedliche Erfahrungsniveaus und Sprachen.

## Nicht akzeptables Verhalten

- Beleidigende, diskriminierende oder herabwürdigende Äußerungen.
- Persönliche Angriffe, Belästigung oder absichtliche Provokation.
- Veröffentlichung privater Daten oder Geheimnisse anderer.
- Absichtlich irreführende oder als falsch markierte Nachweise (Tests,
  Protokolle, Reviewergebnisse).

## Meldung und Durchsetzung

Verstöße meldest du über einen GitHub-Issue an den Repository-Eigner
(M0P) oder auf privatem Weg über GitHub (Direktnachricht an den Eigner).
Sicherheitsrelevante Meldungen gehören nicht in öffentliche Issues — siehe
`SECURITY.md`.

Der Eigner kann Beiträge löschen, Gespräche schließen und Mitwirkende
ausschließen, die gegen diesen Kodex verstoßen. Gegen Entscheidungen kann
sachlich Einspruch eingelegt werden.
