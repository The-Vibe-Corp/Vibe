## Merge-/Push-Plan für das öffentliche Repository (`M0P/Vibe`)

Ausgangslage (geprüft): Remote `origin` zeigt auf
`https://github.com/M0P/Vibe.git`; auf origin existiert `origin/main` @
`c6b2a6c`; der lokale `master` @ `5d806a8` (AP05) ist veraltet; ein lokaler
Branch `main` existiert nicht. Der Paketbranch enthält `c6b2a6c` und liegt
0 Commits hinter `origin/main` — ein Fast-Forward-Push auf `origin/main`
ist möglich. Gemessen am Doku-Commit `bf53999` liegt der Branch 8 Commits
vor `origin/main`; diese
Vorlauf-Zahl erhöht sich mit jedem Paket-Commit, während „0 dahinter“ als
Fast-Forward-Eigenschaft erhalten bleibt. Kein Netz- oder Push-Aufruf ist
im Paket erfolgt (keine Freigabe, SPEC).

1. **Merge des Paketstands:** Der Paketlauf mergt diesen Branch in den
   Integrationsstand. Ziel-Branch des Pushs ist `origin/main`; der lokale
   `master` ist veraltet und müsste vor einem Push zunächst auf den
   geprüften Stand gebracht werden (Fast-Forward oder Merge-Commit des
   Integrationsstands).
2. **Vor dem Push prüfen:**
   - `git status` sauber; `bash scripts/verify.sh quick` Exit 0;
   - `python3 scripts/check-no-secrets.py` Exit 0;
   - `python3 -m unittest tests.unit.test_ap12_github_readiness -v` OK;
   - `git ls-files` enthält keine lokalen Einstellungen
     (`.vibe/`, `.opencode/`, `opencode.json`, `TICKETS.md`, `FEEDBACK.md`).
3. **Push mit Freigabe (Nutzerentscheid, zwei Optionen):**
   - **Option A — Stand pushen wie er ist:** aus dem geprüften Stand
     heraus `git push origin HEAD:main`. Einfachste Variante (Fast-Forward
     auf `origin/main` ist möglich); die Commit-Historie bleibt
     vollständig sichtbar.
   - **Option B — bereinigter Erststand (empfohlen, wenn die Historie
     privat bleiben soll):** lokalen Stand als einzelnen Orphan-Commit
     exportieren (z. B. `git checkout --orphan github-public && git
     commit -m "Erste öffentliche Veröffentlichung"`) und diesen Branch
     als `main` pushen. Das lokale Repository und seine Historie bleiben
     unangetastet; nur der gepushte Stand ist ein neuer, bereinigter
     Verlauf.
4. **Bekannter Grenzpunkt:** Die lokale Historie enthält in alten
   Revisionen persönliche Home-Pfade (`/home/<OS-Benutzername>` in
   ca. 15 Dokumenten, u. a. bis Commit `fc102b2` zurückreichend). Der
   aktuelle Stand ist
   bereinigt; die Historie selbst umschreibt dieses Paket nicht (verboten
   ohne Freigabe). Wer die Historie öffentlich pusht, macht diese
   Altstände sichtbar — deshalb Option B für einen wirklich freien
   öffentlichen Stand empfohlen.
