# GH-88 — Small improvements to the output view

Ticket: GH-88 „kleine Verbesserungen ui Ausgabe“ (branch `feature/m0p/gh-88`, start commit `b525805`). This package changes the Nova output view (`bin/web/nova-output.js`, `bin/web/nova.css`): follow mode for live logs, one responsive card grid, card styling from design tokens, and removal of the redundant status line. The classic `.bv-*` output view is unchanged.

> The layout parts of this record (one shared grid, log heights, summary strip) are superseded by [GH-100](GH-100.md); this page remains the historical account of follow mode and the first grid.

## What changed

**Follow mode (requirement 1).** Each log container (main log and every subagent card log) now has a small `nvOutFollow` helper. A user `scroll` event computes whether the viewport is within 24 px of the end; new output only scrolls to the bottom while that is true. When the user scrolls away, `write()` replaces the rendered log text but restores the previous `scrollTop`, so the selected position stays readable while output continues to arrive in the background. Scrolling back to the end re-enables following immediately. A guard flag keeps programmatic scrolls out of the user-scroll detection; focus/expand calls re-read the position without moving a user-selected one.

**Shared responsive card grid (requirement 2).** The main agent card and all subagent preview cards now live in one grid (`[data-nv-out-cards]`, `repeat(auto-fit, minmax(min(100%, 24rem), 1fr))`). The old `[data-nv-out-subs]` container is kept as a stable hook and joins the grid via `display: contents`. Cards wrap on narrow viewports and share columns at wider ones; no horizontal panel overflow. The summary strip and the sticky control block remain above the grid. Focus/expand still opens exactly one log as a full-area view.

**Card styling (requirement 3).** Static inline layout styles on the preview cards, their heads, and their logs were moved into CSS classes in the existing output block of `nova.css`. Head rows, session codes, roles, and spacing use the existing `--nv-*` tokens and the `.nv-card` look; base log heights come from CSS while the dynamic `max-height` stays inline so focus/expand can toggle it. Slide-in animation is disabled for preview cards so a fast rebuild does not briefly offset the grid. All selectors and `data-*` hooks used by scripts and tests are preserved.

**Status line removed (requirement 4).** The `overview` row with `statePill`, `agentLabel`, and `countLabel` (rendered as “läuftHauptagent: vibe-agent1 Subagenten”) is gone. Run state remains visible in the main card and in each summary row, so no status information is lost. The dual-render guard for the older project stub now checks `[data-nv-out-cards]` instead of the removed marker.

`docs/import-manifest.json` records the new sizes/hashes of the two changed program files and a change-log entry for GH-88.

## Scope decisions

- The two live-log render paths are the Nova view and the classic view. Only Nova needed a change: the classic view already had a `near`-based follow check. Classic browser tests were re-run as regression evidence but not edited.
- The overview element was removed completely rather than left empty as a test anchor. Existing tests now wait on `section[data-nv-out-main-wrap]` and verify the subagent count by counting visible cards; the “two subagents” assertion was replaced, not dropped.
- Keeping `[data-nv-out-subs]` with `display: contents` retains a stable selector for scripts and tests while letting main and sub cards share one set of grid columns.

## Tests

The independent test agent derived coverage from the ticket and spec and wrote the tests before production changes. `tests/browser/test_output_ui.py` gained `OutputCardBehaviorTest` with five behavior-based cases:

1. main log keeps a user-chosen scroll position while new lines arrive, then follows again after the user returns to the bottom;
2. the same for a subagent card log;
3. one shared grid at 1400/900/400 px with no horizontal overflow and the main card occupying a grid cell at 1400 px;
4. no static inline styles on cards/heads/containers, log heights limited via CSS, token-based spacing and a card frame consistent with `.nv-card`;
5. no residual overview labels, two visible cards, and “läuft” visible in both the main card and the summary row.

`SubGridTest` was adapted from “both sub cards share a row inside `[data-nv-out-subs]`” to the equivalent shared-grid contract (two columns, main card plus one sub in the first row, the second wrapping, no overflow outside the panel). Other wait anchors and the run-state read were moved to stable elements without weakening their assertions.

Browser infrastructure worked; the red phase was not caused by a missing environment.
