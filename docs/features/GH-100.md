# GH-100 — Correct the GH-88 layout

Ticket: GH-100 „GH-88-Layout korrigieren“ (branch `feature/m0p/gh-100`, start
commit `abc9f94`). This package corrects the Nova output layout introduced by
GH-88 in `bin/web/nova.css` and `bin/web/nova-output.js`. Follow mode,
focus/expand, `Escape`, steering, the data hooks, and the classic `.bv-*` view
are unchanged.

## What changed

**Compact overview (requirement 1).** The summary strip is now a responsive
grid (`repeat(auto-fit, minmax(min(100%, 22rem), 1fr))`) instead of a
horizontally scrolling flex row. Each summary row wraps its content inside its
cell. The inline layout styles were moved into the existing output block of
`nova.css`; `data-nv-out-summary`, `data-nv-out-summary-row`,
`data-nv-summary-target`, `data-focus`, and click-to-focus are preserved.

**Main-agent rows (requirement 2).** `.nv-out-main-wrap` spans all grid columns
(`grid-column: 1 / -1`). Because main cards precede `[data-nv-out-subs]` in the
DOM, every main agent occupies its own full-width row; only subagent windows
share the grid below. `[data-nv-out-subs]` keeps `display: contents`, so both
windows still participate in one grid container.

**Subagent grid and width (requirement 3).** The subagent grid keeps the
established `repeat(auto-fit, minmax(min(100%, 24rem), 1fr))`. Below 24rem of
available width it collapses to one column; `.nv-log` keeps `white-space:
pre-wrap` and `overflow-wrap: anywhere`, and heads keep `flex-wrap: wrap`.
Neither grid scrolls horizontally at 1400, 900, or 400 px.

**Definite window heights (requirement 4).** `.nv-out-main` and
`.nv-out-sub-log` now use a definite CSS `height` with `overflow: auto`
instead of `max-height`. Heights change only at layout breakpoints: 22rem /
16rem by default, 18rem / 13rem at ≤900 px, 16rem / 12rem at ≤600 px. Long
output scrolls vertically inside its window and never grows the card. Focus and
“Alles anzeigen” still lift the fixed height (`.nv-out-log-open` sets
`height: auto`; the enlarged overlay continues to flex and scroll).

**Behavior unchanged (requirement 5).** `setLogLimit()` now toggles the
`nv-out-log-open` class instead of writing an inline `max-height`; it still
updates `aria-expanded`, the button label, and refreshes the follow helper.
Focus, `Escape`, steering, resume, syntax highlighting, and all data hooks are
untouched.

## Scope decisions

- Overview minimum cell width is 22rem; the subagent grid keeps the established
  24rem readability minimum from GH-88.
- Breakpoints are 900 px and 600 px. These are specific to the output windows;
  they do not change or claim to match the existing Nova shell breakpoints.
- Open/focused logs are expressed as a CSS class so the static log styling
  stays in CSS; no inline layout style is required for the normal state.
