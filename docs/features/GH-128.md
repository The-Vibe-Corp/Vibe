# GH-128 — GitHub issue sync button under the project Work section

Delivery record for ticket GH-128. Work was done on `feature/m0p/gh-128`
from start commit `563fa4b`; no production installation was modified.

## What changed

- `bin/web/nova-project.js` moves the single `Sync issues` button
  (`data-nv-action="issues-sync"`) out of the Git & GitHub settings card and
  into the project hero action row (`[data-nv-hero] .nv-hero-actions`), next to
  `Add package`, `Report bug`, and `Give feedback`. That header is shared by
  all project tabs, so the button appears above the Work board, before the
  filter bar, and on the other tabs as well.
- The button is only created when the `github` feature is enabled. It starts
  hidden and becomes visible after `/api/project` loads, only when
  `data.github.issues_enabled` is truthy. The early load-error path leaves it
  hidden.
- The click handler keeps the previous behavior: `nvpPost` posts
  `{action: 'issues.sync'}` to `/api/github` with the project name, respects
  `NV.stale(token)`, toasts the server message (falling back to the existing
  `Issues synchronisieren` label), and calls `NV.render()` after a successful
  sync so the Work board reflects imported issues.
- The Git & GitHub settings section keeps the opt-in checkbox
  (`github-issues-enabled`), the In-Progress/Ready/Assignee fields, and the
  explanation paragraph; only the duplicated sync button was removed.
- No backend, classic UI, feature flag, state/schema, or cache change was made.
- `docs/import-manifest.json` carries a GH-128 change entry and the refreshed
  size and SHA-256 of `bin/web/nova-project.js`.

## Scope decision

Autonomous mode was active. The ticket asks for the sync action to appear under
the project Work section instead of being hidden in the settings; the smallest
coherent change is to move the existing single button into the always-visible
hero row and gate it on the already-existing GitHub feature and project
opt-in. Duplicating the button or adding a second entry point was rejected.
